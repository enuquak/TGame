# 全仓库代码规范整理计划

**Goal:** 将当前手写代码按项目规范整理，保持业务行为和外部协议不变。

**Architecture:** 沿用现有目录和类型职责。使用编译器感知的格式工具补齐 C# 控制语句花括号；人工检查逻辑段落、提前返回、安全的声明排序及业务常量。

**Tech Stack:** .NET 10、C#、PowerShell 7、Python、JavaScript、Shell、BAT。

**Spec:** `code/agents/项目协作规范.md`，以及用户要求所有单行控制语句也使用花括号。

## 约束与审阅重点

- 生成代码、第三方工具及运行产物不参与源码整理。
- 不因排序改变初始化副作用、异常时机、取消或资源释放顺序。
- 保留协议值、日志字段、HTTP 状态码含义、脚本退出码和配置格式。
- 常量放在拥有对应职责的类型或模块中；已有声明优先复用，不添加无用抽象。
- 保留 `Program.cs` 已有的手动声明排序；本次统一整理覆盖该文件。
