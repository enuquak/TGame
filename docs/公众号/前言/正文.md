# 写在前言

不知不觉已经入行五年多了

回头看这一路，感觉自己已经想了很多，也做了很多了，但是细思下来又确实有很多的地方，让人觉得不甚清晰

在行业寒冬和 AI 的冲击下，对未来又是一片茫然，不由得让我对了解自己，产生了一种冲动，我想更清晰地了解，我自己的能力边界，在哪里

一路上见过了很多的服务器引擎和业务框架，好的很多，烂的也不少，有些能看实现，有些只能看文档

于此打算写一个游戏服务器系列，从0搭建一个，符合我心意的游戏服务器（当然是在AI的辅助下，毕竟不是原始人了

写公众号，一方面是写下文字，是对自己想法的一种沉淀，也方便我自己，以后回过头来了解下现在的我是怎么想的

另一方面也是对自己一个督促作用，毕竟我还是一个挺容易懈怠的人，有明确的产出的目标，也算有点激励作用，毕竟，我现在应该也还没处于想写的都写完了的状态

当然，如果有看客对其中的一些思想和实现有自己的想法，也非常欢迎进行交流！

预计是每3~5天能出一篇文章，4~6个月完结这个系列
