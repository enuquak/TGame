# 源码协作入口

开始工作前，必须读取并遵守 [项目协作规范](agents/项目协作规范.md)，该规范适用于整个仓库。

开始新事项时先创建[事项分支](agents/项目协作规范.md#git-事项分支)，在分支上提交，验证后合并回 `main`。

进程名和类名遵循[命名约定](agents/项目协作规范.md#命名约定)。新增配置或类型映射时，遵循[配置与注册](agents/项目协作规范.md#配置与注册)约定。

目录职责与生成规则见 [项目文件结构](../docs/项目文件结构.md)。保持 `client/`、`server/` 对称；业务改动按需涉及 `shared/` 和 `tests/`。`generated/` 中的代码由源定义生成，不手工修改。

本目录是 Codex 日常工作目录。项目工具位于 `../tools/`，策划源文件位于 `../design/`；需要开发工具、导出或排查资源时按需访问。文档中注明“项目根目录”的命令，应从本目录的上一级运行。
